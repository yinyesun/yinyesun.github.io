# 小红书手机端交互 Demo

直接打开 `index.html` 即可体验；也可以在此目录运行 `python3 -m http.server 4173`，然后访问 `http://localhost:4173`。

建议用 375×812 手机视口检查。主路径：甜品搜索 → 笔记 → 点击星星收藏（变黄、收藏数变为 161）→ 邀请加入经验池弹窗 → 主题经验池 → 具体经验池 → 点点总结弹窗 → 完整点点总结 → 真人经验来源 → 向真人提问 → 社区回答 → AI 更新。关闭总结弹窗会回到社区聊天，点击左下角「点点总结」可重新打开；点击各页面头像可进入用户主页，再返回原页面。原型还包括问题记录、经验池设置，以及移除危险确认分支。桌面端右侧有步骤导航，手机端点击原画面中的对应控件。

这是用于确认交互与视觉的原型，不会向真实小红书发布问题、删除内容，也没有接入 AI 服务。全部 17 张界面均来自用户提供的 1125 × 2436 高清设计图。
