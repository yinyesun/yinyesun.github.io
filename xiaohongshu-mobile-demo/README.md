# 小红书手机端交互 Demo

直接打开 `index.html` 即可体验；也可以在此目录运行 `python3 -m http.server 4173`，然后访问 `http://localhost:4173`。

建议用 375×812 手机视口检查。主路径：甜品搜索 → 笔记 → 邀请加入经验池弹窗 → 经验池 → 点点总结 → 向真人提问 → 确认发布 → 社区回答 → AI 更新。原型还包括来源追溯、问题记录与经验池设置分支。桌面端右侧有步骤导航，手机端点击原画面中的对应控件。

这是用于确认交互与视觉的原型，不会向真实小红书发布问题，也没有接入 AI 服务。全部 12 张界面均来自用户提供的 1125 × 2436 高清设计图。
